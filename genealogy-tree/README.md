# Genealogy Tree Application

This project is an interactive genealogy tree application that allows users to visualize and manage family relationships. It provides functionalities to add, remove, and display family members in a user-friendly interface.

## Project Structure

```
genealogy-tree
├── src
│   ├── index.html       # Main HTML document for the application
│   ├── script.js        # JavaScript file for interactive functionality
│   └── styles.css       # CSS file for styling the application
└── README.md            # Documentation for the project
```

## Features

- Add family members to the genealogy tree
- Remove family members from the tree
- Display family relationships visually
- Responsive design for various screen sizes

## Getting Started

To set up and run the application, follow these steps:

1. Clone the repository to your local machine:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd genealogy-tree
   ```

3. Open the `src/index.html` file in a web browser to view the application.

## Usage

- Use the provided interface to add new family members by entering their details.
- Click on family members to remove them from the tree.
- Explore the relationships displayed in the genealogy tree.
